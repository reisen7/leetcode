# LeetCode 刷题记录

使用 Python 记录 LeetCode 题解，文件由 VS Code 的 LeetCode 插件生成，命名格式为 `题号.题目名.py`。

## 说明

- 语言：Python 3
- 编辑器：VS Code + [LeetCode 插件](https://marketplace.visualstudio.com/items?itemName=LeetCode.vscode-leetcode)
- 每个文件包含题目代码（`@lc code=start` 到 `@lc code=end`）以及测试用例

## 运行

直接在 LeetCode 插件中打开对应文件即可运行/提交；也可以当作普通 Python 文件执行：

```bash
python 1.two-sum.py
```
